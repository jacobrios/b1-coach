# THE SEED, AND WHY THERE ARE TWO ROUNDS.
#
# Session 1 is the same fifteen swings at any seed, but sessions 2, 3 and 4 are
# GENERATED from it with a seeded PRNG, so the seed alone decides what those
# sessions contain. This round is seed 20260819, which is a DIFFERENT seed from
# ../before and ../after-a, both of which are 20260814. That is deliberate and
# it is why this directory exists. A generator rewrite moves ALL the data, so a
# single seed measures one excursion rather than a result, and this project has
# twice reported a single-seed excursion and then had to correct it. ../after-a
# is the seed-matched comparison against ../before; this round is the check that
# whatever ../after-a shows is not an artefact of one draw. There is no
# seed-matched before side at 20260819 and this round is not claiming one.
#
# THE POP-UP NOTE THIS SEED CARRIES, MEASURED BEFORE THE MONEY WAS SPENT.
#
# At seed 20260819 five cells (power-s2, contact-s4, open-s4, allfields-s4,
# popup-s4) carry exactly ONE pop-up each, so roughly 40 of these 64 debriefs
# are written about a session containing a single pop-up swing. That is the
# opposite of ../after-a, where the count is zero everywhere, and it is the
# reason both seeds are worth having. Neither seed exercises the pop-up change
# hard enough to measure it: the bench builds each cell's sessions once outside
# the run loop, and the four session-4 cells are 89% correlated, so the whole
# bench sees at most a handful of distinct pop-up draws. The evidence that the
# pop-up work landed is the deterministic measurement, 0.394 pop-ups per
# session across 400 seeds and 18,000 swings, not this round. Do not read a
# null pop-up result here as evidence the fix did not land.
#
